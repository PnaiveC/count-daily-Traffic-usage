# 每日流量 MVP 需求基线

版本：2.1（2026-10-17）  
状态：唯一有效需求，替代 `docs/archive/` 中的旧文档。

## 1. 目标

提供一个极简 Android 工具，准确查看指定日期内：

- 设备当天移动数据 + Wi-Fi 的总用量；
- 当天各应用/UID 的用量，按用量从高到低排列。

所有数据来自 Android 系统 `NetworkStatsManager`，本地读取。应用无广告、无账号、
无联网权限、无后台服务、无本地历史数据库。

## 2. 用户场景

用户发现流量异常，打开应用后默认查看今天，也可以切换到过去某一天，快速看出
当天哪些应用消耗了流量。

## 3. MVP 功能

### F1. 单页界面

只做一个页面，从上到下依次为：

1. 日期栏：前一天、当前日期、后一天；点击日期打开系统日期选择器。
2. 设备总流量：所选日期、当前网络筛选下的总用量。
3. 网络类型漏斗、帮助和刷新入口。
4. 应用列表：图标、名称、当天总用量；不显示 0 用量行。
5. 点击应用可向下展开最近 7 日用量。

不提供应用详情页、图表、卡片组、导航栏、设置页或关于页。日期范围选择暂不实现，
留到后续版本。

### F2. 日期

- 默认选择今天。
- 不允许选择未来日期。
- 查询范围使用设备当前时区：
  - 过去日期：当天 00:00 到次日 00:00；
  - 今天：当天 00:00 到查询时刻。
- 日期切换后立即重新查询。
- 页面回到前台时重新检查日期和权限，并刷新当前日期。
- 不使用数据库保存历史；系统能提供多久就查询多久。
- 当前版本只选择单日；起止日期范围不在本版范围内。

### F3. 使用情况访问权限

- 使用 `PACKAGE_USAGE_STATS`，必须由用户在系统设置中手动开启。
- 未授权时显示简短说明和“去授权”操作，不查询、不崩溃。
- 优先跳转 `Settings.ACTION_USAGE_ACCESS_SETTINGS`。
- 跳转失败时回退到应用详情设置页。
- 从设置返回后自动重检权限并加载。

### F4. 数据查询

- 分别通过 `NetworkStatsManager.querySummaryForDevice` 查询移动数据和 Wi-Fi。
- 分别通过 `NetworkStatsManager.querySummary` 查询按 UID 数据，再按 UID 合并。
- `subscriberId` 传 `null`，不区分 SIM 卡。
- 应用名称和图标通过 `PackageManager.getPackagesForUid` 解析。为保证所有
  UID 都能映射到本机应用，声明 `QUERY_ALL_PACKAGES`；该权限仅用于本地包
  信息读取，应用仍不申请 `INTERNET`。
- 所有系统查询、包信息读取、排序都在工作线程执行。

### F5. 特殊 UID

- `UID_ALL` 不进入应用列表。
- `UID_TETHERING` 显示为“网络共享”。
- `UID_REMOVED` 显示为“已卸载应用”。
- 系统 UID 能解析时显示系统名称，否则显示“系统 (UID n)”。
- 无法解析的普通 UID 显示为“未知应用 (UID n)”。
- 唯一 UID 直接显示对应应用名称和图标。
- 共享 UID 不显示“多个应用”；全部合并到列表底部的“其它”汇总行。
- “其它”显示共享 UID 组数、包数和合计流量。
- 点击“其它”展开每个共享 UID 组；点击组显示具体包名和该 UID 的七日趋势。
- 图标读取失败使用系统默认图标，不影响字节数显示。

### F6. 状态

必须区分并展示：

- 加载中；
- 查询成功且有数据；
- 查询成功但当天为零；
- 未授权；
- 读取失败。

规则：

- 查询成功且数值为零：显示 `0 B`。
- 任一网络类型查询返回 `null` 或抛异常：视为读取失败，不把该类型伪装成 0。
- `SecurityException`：按未授权处理。
- 应用查询成功但没有 UID 记录：显示“当天无流量记录”。
- 取消/页面销毁导致的结果不展示，不弹错误。

### F7. 网络筛选与帮助

- 漏斗图标打开网络类型选择：全部网络、移动数据、Wi-Fi。
- 切换筛选后，设备总量、应用排序、“其它”合计和七日趋势都使用所选网络。
- 当前筛选在设备总量标签中明确显示。
- 帮助图标打开轻量弹窗，解释系统数据口径、共享 UID、七日趋势和历史保留限制。

### F8. 最近七日展开

- 点击唯一 UID 应用向下展开最近 7 日用量。
- 七日区间以当前选中日期为结束日，向前包含 7 天。
- 同一时间只展开一个应用或共享 UID 组。
- 七日数据按需加载并缓存；切换日期或网络筛选后清除缓存。
- 当前筛选为 Wi-Fi 时只显示 Wi-Fi，移动数据时只显示移动数据，“全部网络”显示合计。
- 读取失败的日期显示“—”；系统历史保留不足时 API 无法可靠区分，可能显示为 0 B。
- 使用简单数字和横条展示，不引入图表库。

## 4. 非功能要求

- Android 6.0+，`minSdk 23`。
- `compileSdk/targetSdk 36`。
- 单 Activity、单页面、单模块。
- 不申请 `INTERNET`，不引入广告、分析、崩溃上报或云服务 SDK。
- 不引入 Compose、Room、数据库、DI 框架、后台服务、通知。
- 不使用第三方 UI 组件；优先使用平台控件和单个工作线程。
- 不按低流量阈值合并应用；唯一的合并规则是共享 UID。
- 查询不阻塞主线程；列表滚动流畅。
- Release 开启 R8 和资源压缩。
- APK 体积目标小于 1.5 MB；以实际构建结果记录。

## 5. 不使用 `NoData` 伪状态

系统 API 无法可靠判断“没有历史记录”还是“数据保留不足”。应用只使用：

- `Success(data)`；
- `PermissionDenied`；
- `Failure(kind)`；
- `Loading`。

应用列表为空是 `Success(emptyList)`，由 UI 显示空状态。

## 6. 已知限制

- 系统统计值和运营商账单不保证一致。
- 统计受系统时间桶和历史保留策略影响，日期边界可能不精确。
- 设备总量与按 UID 求和不保证相等。
- VPN、共享 UID、系统 UID 和网络共享可能导致归属差异。
- 双 SIM 合并统计，不区分卡。
- 不提供长期历史记录和导出。
- 共享 UID 无法拆分到单个包；只能在组内展示包名。
- 日期范围选择尚未实现。

## 7. 验收

- 未授权时不查询、不崩溃，能进入授权设置并从返回后恢复。
- 今天、过去日期、跨午夜、月初和跨年时日期范围正确。
- 设备总流量和列表按所选日期刷新。
- 网络筛选能正确影响总量、排序、“其它”和七日数据。
- 帮助弹窗内容与实际行为一致。
- 查询失败、真实零流量、空列表三种情况可区分。
- 唯一 UID 直接显示；共享 UID 只出现在底部“其它”，可逐层展开。
- 特殊 UID 和无法映射 UID 不会被静默丢弃。
- 点击应用或共享 UID 能展开最近 7 日，并正确处理缺失日期。
- Release merged manifest 不含 `INTERNET`。
- `assembleDebug`、`assembleRelease`、JVM 单元测试通过。
- API 36 模拟器完成基本流程验证；真机多品牌验证在设备可用后补做，
  未完成时不得标记为已通过。
